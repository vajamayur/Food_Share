# FoodShare React - Responsive Design

The project has been updated with a responsive CSS layer for desktop, tablet,
mobile, and very small phone screens.

## Supported breakpoints

- Desktop: above 992px
- Tablet: 577px–992px
- Mobile: up to 576px
- Small phones: up to 380px

## Run

```bash
npm install
npm run dev
```

The responsive layer preserves the existing UI while making common grids,
forms, navigation, dashboards, modals, images, and tables adapt to smaller
screens.
