# FoodShare React — Restructured Pages

The project now has a dedicated React `src/pages/` structure and a central
`src/pageRegistry.js`.

Pages:
- Home: `/`
- Login: `/login`
- Signup: `/signup`
- About: `/about`
- Contact: `/contact`
- Donor Dashboard: `/donor-dashboard`
- NGO Dashboard: `/ngo-dashboard`
- Volunteer Dashboard: `/volunteer-dashboard`
- Admin Dashboard: `/admin-dashboard`

`src/AllPages.jsx` provides an "All Pages" launcher.

Run:
```bash
npm install
npm run dev
```
